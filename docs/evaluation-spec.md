# Native Speaker Evaluation & Production Gate Specification

## 1. Evaluation Protocol
- **Panel**: 20–30 native Central Kurdish listeners using high-fidelity headphones.
- **Method**: Double-blind randomized A/B playback with paired MOS ratings (1–5 scale).
- **Categories**:
  1. Naturalness
  2. Sorani Pronunciation Accuracy (velar ڵ, trill ڕ, vowels ێ, ۆ, ە)
  3. Speaker Similarity
  4. Emotion / Style Authenticity
  5. Long-form Stability

## 2. Hard Production Gates
- **Win Rate**: ≥ 55% blind preference over baseline F5-TTS model.
- **Pronunciation**: ≥ 95% native listener acceptance (MOS ≥ 4.5).
- **CER**: Automated Character Error Rate < 4.0% on held-out test suite.
- **Failure Rate**: < 1% stop failure or repetition stutter.
- **Latency**: P95 TTFB < 500 ms under warm production traffic.
